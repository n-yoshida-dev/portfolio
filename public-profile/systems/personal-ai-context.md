## 何を解いているか

AI サービスを用途別に使い分けると、「自分がどういう状況で、何を決めてきたか」が各サービスのメモリに分散します。
サービスを乗り換えると文脈が消え、同じ説明を繰り返すことになります。

そこで、**自分に関する長期コンテキストを Markdown で 1 か所に持ち、どの AI にもそれを読ませる**形にしました。
このリポジトリは非公開で、内容はここには載せません。載せるのは設計の考え方だけです。

## 設計

```
personal-ai-context（非公開・Markdown）
  ├─ 入口：現在地の要約（基準日付き）と、判断基準・回答スタイル
  ├─ テーマ別の詳細（経歴・学習・プロジェクト・環境 など）
  ├─ 履歴：重要な意思決定（以前 / 現在 / 変更理由）
  └─ メタ：更新ルール、未確認事項・矛盾候補
        ↓ 読ませる順序を README に固定
ChatGPT / Claude.ai / Claude Code / Gemini
```

- **current state / history / decisions を分ける**：「現在」「過去」「目標」「検討中」「却下済み」を混同させない
- **数字には基準日を付ける**：年齢・計画などを恒久的事実として扱わせない
- **推測で補完させない**：リポジトリに無い情報を、もっともらしさで埋めないルールを明記
- **一次情報を分散させない**：各プロジェクトの実装状況はそのリポジトリ、習熟度は学習リポジトリを一次情報とし、ここには目的と判断だけを置く
- **秘密は最初から入れない**：パスワード・API キー・口座やカードの番号・正確な住所は追加しない。機密の数字はフックが機械的にブロックする

## 運用

1. 新しい事実・決定に日付を付ける
2. 現在地の要約に影響するなら、先にそれを更新する
3. テーマ別の詳細を更新する
4. 方針転換なら「以前 / 現在 / 変更理由」を履歴に追記する
5. 不確実な情報は「未確認事項」へ分ける
