## 経歴

| 時期 | 役割 | 身についたこと |
|---|---|---|
| 2016〜2018 | 事業会社の情報システム担当。ヘルプデスク、PC 調達、仮想基盤の保守、全国拠点のネットワーク管理。現場業務（物流）も兼務 | 現場の業務を理解したうえで IT を考える視点。関係者調整、厳しい状況で仕事を完遂すること |
| 2019〜2020 | SIer で IT 資産管理・クライアント管理製品の設計・構築エンジニア | ネットワーク、セキュリティ、可用性などインフラの基礎。顧客折衝 |
| 2020〜2024 | 同領域でチームリーダー。案件推進、7〜8 名のアサイン・教育・ドキュメントレビュー、プリセールス | 仕様化、見積、レビュー、チーム運営 |
| 2025〜 | アプリケーション開発部門へ異動（本人希望）。システム刷新・基盤移行の移行計画、テスト計画、結合・システムテスト、課題管理、複数案件のリード | テスト工程の実務、計画と課題管理、不確実な状況で仕事を前へ進めること |

**正直に書いておくこと**：業務でプロダクションコードを継続的に書いた経験はまだありません。
Java のソースを読む・ビルドすることはあっても、書く仕事ではありませんでした。
そのため、実装力は個人開発で積み、根拠を公開する形にしています。

## 今の方向

バックエンド（Go / Java）を軸に、フロントエンド（React）も扱える形で、
自社プロダクトを継続的に改善する開発に携わることを目指しています。
SIer で培った仕様化・調整・テストの経験と、個人開発で積んでいる実装力を組み合わせるのが自分の強みだと考えています。
