## あなたが判断したこと

- 表示の確認：Playwright（Chromium）で 1280×800 と 375×812、ライト／ダーク、開いて 4 秒後と `prefers-reduced-motion: reduce`、開いて 0.4 秒の途中を撮って確かめた。どの条件でも横スクロールは出ない（scrollWidth = 画面幅）。表紙の下端は 1280×800 で 800px、375×812 で約 812px
- 文字の確認：見本の文字列（本文のテキストノード・`aria-label`・`title`・`<title>`）を index.html のものと機械で突き合わせ、元に無いものは「01〜07」と「続き ↓」だけであることを確かめた
- 「表紙の下に何が続くか」の示し方は、節名を並べると目次と重なるので「続き ↓」の 1 語にした
- 外部リンクのカード 3 枚は表紙に入れず、表紙の直後（1 画面目の下）に置いた。表紙を名前と要点だけにするため。左の目次の GitHub / Qiita で代わりが効く
- 375px の表紙の高さは「画面の高さ − 10rem（上部の名前と目次 2 行 + 本文の上余白）」で決めた。目次が 3 行に折り返す端末では数十 px ずれるが、崩れはしない
- 要点の補足の文字を 0.95rem → 0.9rem にし、問いの列を 10rem にした（1280px で「い）」だけが 2 行目に落ちるのを避けるため）
- JavaScript は今の目次のスクロール監視をそのまま使い、足していない。動きは CSS だけ
- 1280×800 の文字数（空白を除く、目次と右下のボタンを含む）は約 300 字。減らす目標ではないが、比べる材料として書く
