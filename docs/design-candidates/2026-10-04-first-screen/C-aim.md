## 狙い

最初は名前と一言を読み、次に関心のある内容を選ぶ、という順序にする。
3 つの要点を About・Projects・Systems の入口に結び付け、内容の説明と移動先の案内を兼ねる。
大きな名前、余白、罫線だけで第一印象を整え、詳しい補足や一覧は読み進めた先に置く。

## 部分ごとの案

- 構成：トップを紹介と索引のページに変更し、その下に About の要点・外部リンクと Ask AI の短い案内を置く。他の一覧は既存の詳細ページで読む。
- 最初の画面に置くもの（1280×800）：Portfolio と GitHub、名前、一言、About・Projects・Systems の要点付きリンク 3 行、Skills・Journey・Articles・Ask AI のリンク。
- 最初の画面に置くもの（375×812）：PC と同じ。要点付きリンクは節名の下に要点を置き、残りの 4 節は横並びにする。
- 見た目：左の目次を外して本文を最大 52rem で中央に置き、名前を PC 最大 68px・375px では 38px に拡大。入口はカードではなく罫線で区切り、続く About 全体に薄い地色を敷く。
- 動き：なし。ホバー時は入口の地色と下線だけを即時に変え、ページ内移動にもアニメーションを付けない。
- 今の 7 節：About → トップの索引から同じページの #about へ。現在の要点 3 つと補足、外部リンク 3 つを省略せず掲載し、/profile.md にもつなぐ。
- 今の 7 節：Projects → 最初の画面の要点付きリンクから今の /projects。一覧カードはトップに掲載しない。
- 今の 7 節：Systems → 最初の画面の要点付きリンクから今の /systems。一覧カードはトップに掲載しない。
- 今の 7 節：Skills → 最初の画面のリンクから今の /skills。区分ごとの内容はそこで読む。
- 今の 7 節：Journey → 最初の画面のリンクから今の /journey。経歴と学習の歩みはそこで読む。
- 今の 7 節：Articles → 最初の画面のリンクから今の /articles。連載・記事の一覧はそこで読む。
- 今の 7 節：Ask AI → 最初の画面のリンクから今の /ask。トップ末尾にも元の説明文とボタンを置く。
- 目次（PC の左・375px の上部）：固定の目次を廃止し、両幅とも紹介の下に 7 節の索引を常時表示する。3 つの主な入口と 4 つの補助リンクに分け、メニューで隠さない。
- 右下の Ask AI ボタン：動かす。文言と /ask へのリンクを保ち、トップ末尾の通常の文書フローに置く。最初の画面では索引の Ask AI を入口とし、固定ボタンが内容に重なる状態をなくす。

## 変える決まり

「1 枚のページ + 左の固定目次」を、短いトップと既存の詳細ページへの索引に変える。
375px の目次は上部の全項目横並びから、紹介の下の 3 行＋4 項目横並びに変える。全項目を初期表示する方針は維持する。
トップの一覧カードを外し、移動先を案内する罫線付きの行に変える。About の外部リンクカードは薄枠・角丸 8px・PC 3 列を維持する。
最初の画面の About は要点の見出しだけを索引に使い、選択済みの「小見出し → 太字の見出し → 補足」の 3 列と外部リンクカードは次の画面に移す。
トップの Skills の区分カード、Journey の年表、Articles の連載 × 公開月の図を掲載せず、各詳細ページへのリンクに変える。詳細ページ自体の変更はこの案に含めない。
本文最大 52rem を維持しつつ、左の目次を除いた左寄せからページ中央寄せに変える。
右下の追従ボタンをトップ末尾に移し、固定表示をやめる。
目次のスクロール監視は廃止する。この見本に JavaScript は使わず、Ask AI の遷移先の動作は変更しない。

## あなたが判断したこと

情報量は文字数だけでなく、初期表示で同時に読む説明とカードの数として扱った。最初の画面には詳細説明や実績一覧を置かず、要点が移動先の案内も兼ねるようにした。
About は既存の詳細 HTML ページがないため、トップ内に残した。約 10 年の担当範囲と、個人開発・学習の補足はそこで元の文のまま読めるようにした。
OrgFlow の要点は Projects、ADR の要点は Systems の入口に対応させた。いずれも個別の成果物への直リンクではなく、関連する内容の一覧に進む。
About の要点は索引と本文で重複する。最初は行き先を判断する短い文として、次は補足を伴う説明として使う。
初期画面の枠は 100svh を最小の高さとし、文字の拡大や狭い画面では内容に応じて縦に伸ばす。About 本文はその直下に置く。
新しい URL は作らず、既存のリンク先と #about を使った。別ページの HTML は提供されていないため、単独ファイルで遷移先まで再現することは対象外とした。
ブラウザ実行環境を利用できず、1280×800・375×812 のライト／ダークとも実描画は未確認。幅は 100%・max-width・minmax() で組み、長文の nowrap と横方向の隠蔽は使っていない。両配色は既存 CSS の色を使用し、静的に確認した。
動きを入れていないため、通常設定と prefers-reduced-motion: reduce の表示は同じになる。
